## لماذا الملف فارغ؟

قاعدة المواصفات §24 صريحة: لا يجوز إنشاء نصوص الأذكار من ذاكرة نموذج لغوي، ولا
اختراع مصدر أو مرجع أو درجة حديث. كتابة نص شرعي من الذاكرة تعني احتمال خطأ في
حرف أو نسبة أو تخريج، وهذا ضرر حقيقي لا يبرره أي مكسب في العرض.

المصادر المرجعية التي حدّدتها المواصفات لم تكن قابلة للوصول أثناء التنفيذ؛ فقد
منعت سياسة الشبكة في بيئة العمل الاتصال بها:

| المصدر | العنوان | النتيجة |
|---|---|---|
| حصن المسلم — IslamHouse | `islamhouse.com` | ‏403 من بوابة الشبكة |
| نص القرآن — Tanzil | `tanzil.net` | ‏403 من بوابة الشبكة |

وعليه نُفِّذ ما تنص عليه المواصفات حرفيًا: بناء التطبيق والمخطَّط وخط الاستيراد
والاختبارات، مع تسجيل المانع هنا بوضوح.

## بوابة الإصدار

```bash
# فحص بنيوي أثناء التطوير
dart run tool/validate_adhkar.dart

# بوابة الإصدار — يجب أن تمر قبل أي بناء للنشر
dart run tool/validate_adhkar.dart --release
```

بوابة الإصدار ترفض الإصدار إذا:

- كانت المجموعة فارغة (الحالة الحالية).
- وُجد سجل حالته ليست `verified`.
- نقص `sourceName` أو `sourceReference` في أي سجل.
- تكرّر معرّف، أو تكرّر `order` داخل القسم نفسه.
- كان `repeatCount` أقل من ١.
- ظهر نص مؤقت مثل `TODO` أو `<النص` أو `placeholder`.
- أشار سجل إلى قسم غير معرَّف، أو إلى ملف صوت غير موجود.
- احتوى العنوان حروفًا لاتينية (مؤشر على نص لم يُترجم بعد).

## كيف تُستورد بيانات موثقة

1. جهّز ملف JSON يطابق المخطَّط أدناه، بنصوص منسوخة حرفيًا من مصدر معتمد.
2. ضعه في `assets/data/adhkar.json`.
3. شغّل `dart run tool/validate_adhkar.dart --release` وأصلح ما ترفضه الأداة.
4. راجع النصوص مراجعة بشرية مؤهلة، ثم اضبط `verificationStatus` إلى `verified`.
5. حدّث جدول المصادر في هذا الملف.

### مخطَّط السجل

```json
{
  "id": "morning_001",
  "categoryId": "morning",
  "title": "عنوان الذكر",
  "text": "النص كما ورد في المصدر حرفًا بحرف",
  "repeatCount": 1,
  "sourceName": "اسم الكتاب أو المصدر",
  "sourceReference": "رقم الباب أو الصفحة أو الحديث",
  "note": null,
  "audioAssetPath": null,
  "keywords": [],
  "order": 1,
  "verificationStatus": "verified"
}
```

`categoryId` يجب أن يطابق أحد معرّفات `assets/data/categories.json`:
`morning`, `evening`, `sleep`, `waking`, `after_prayer`, `wudu`, `home`,
`mosque`, `food`, `travel`, `distress`, `illness`, `weather`, `gatherings`,
`misc`.
