## 6. ما تم تنفيذه

**الأساس** — Flutter/Dart stable، بنية Feature-first، Riverpod، go_router، واجهة عربية RTL من الجذر، خط Noto Sans Arabic بترخيص OFL مضمَّن محليًا بلا أي تنزيل وقت التشغيل، ثيم فاتح وداكن بألوان المواصفات حرفيًا، أيقونة متكيّفة وشاشة بداية مولَّدتان من العمل الفني الأصلي.

**البيانات** — نماذج كاملة، قارئ أصول يكتشف كل حالات الفساد، مستودعات فوق تخزين مجرَّد، وأداة `tool/validate_adhkar.dart` بوضعَي فحص وبوابة إصدار.

**القراءة** — ذكر واحد لكل شاشة، شريط تقدُّم، مصدر قابل للطي، عدّاد لا يتجاوز العدد المطلوب، اهتزاز إكمال واحد، انتقال تلقائي اختياري، شاشة «تم وردك»، حفظ الموضع، واستئناف يسأل عند تقادم الجلسة.

**المفضلة والبحث** — تخزين المعرّفات فقط، وبحث عربي يتجاهل التشكيل والتطويل ويوحّد صور الحروف — **للمطابقة فقط دون المساس بالنص المخزَّن**.

**الإعدادات** — الأقسام السبعة كاملة بالافتراضيات المنصوص عليها، بما فيها **«إبقاء الشاشة مستيقظة أثناء الورد»** المنفَّذ عبر `wakelock_plus` ويسري ويُلغى تلقائيًا عند دخول شاشة الورد ومغادرتها.

**الصوت** — `NarrationService` مجرَّد بتنفيذين (محرك الجهاز، وتسجيلات مرفقة) وموجّه يقدّم التسجيل البشري متى وُجد؛ كشف العربية يجرّب `ar-SA/ar-EG/ar-AE/ar-JO/ar` بلا فرض لهجة؛ رسالة محترمة عند الغياب؛ إيقاف بأدب عند المقاطعة؛ وإيقاف تلقائي عند مغادرة الشاشة. **لا يُرسل نص الذكر إلى أي خدمة خارجية.**

**التذكيرات** — محلية بالكامل، لا تُطلب صلاحيتها إلا عند تفعيل المستخدم لتذكير، جدولة غير دقيقة تجنّبًا لصلاحية `SCHEDULE_EXACT_ALARM`، وإعادة جدولة تلقائية عند عودة التطبيق للمقدمة لتصمد أمام تغيّر المنطقة الزمنية.

**التواصل والتسبيح** — رقم المطوّر في ملف واحد فقط، وروابط مبنية بترميز صحيح، وفتح خارجي بلا أي إرسال تلقائي؛ وعدّاد تسبيح بأهداف ٣٣/١٠٠/مفتوح.

**سهولة الوصول** — مساحات لمس ≥48dp (و≥64dp لكبار السن)، تحمّل تكبير خط النظام حتى ٢٠٠٪، دعم الوضع الأفقي، Semantics تُعلن نص الذكر والعدد وحالة الإكمال وزر الصوت، وعدم الاعتماد على اللون وحده ولا على السحب وحده.

الاختبارات الآلية لا تغني عن الفحص اليدوي التالي:

1. مظهر الأيقونة على مشغّل التطبيقات وقراءة «ذكري» بوضوح عند 48px.
2. شاشة البداية على أندرويد 12 فأحدث.
3. اهتزاز حقيقي عند الإكمال، وسكونه التام عند إطفاء المفتاح.
4. نطق عربي فعلي على جهاز فيه صوت عربي، وآخر بلا صوت عربي.
5. توقّف الصوت أثناء مكالمة واردة.
6. وصول تذكير مجدول فعليًا، وبقاؤه بعد إعادة تشغيل الجهاز.
7. فتح واتساب والرسائل والهاتف، والسلوك عند عدم تثبيت واتساب.
8. التشغيل في وضع الطيران بعد إغلاق التطبيق تمامًا.
9. قارئ الشاشة TalkBack على جهاز حقيقي.
10. جهاز قديم بـ minSdk 24 وأداء الإقلاع عليه.

## 9. خطوات بناء APK

على أي جهاز فيه Android SDK (ANDROID_HOME مضبوط) وJava 17:

```bash
cd dhikri
flutter --version                               # يجب أن يكون stable
flutter pub get

# بوابة المحتوى — يجب أن تمر قبل أي بناء للنشر
dart run tool/validate_adhkar.dart --release

# بوابات الجودة
dart format . && flutter analyze && flutter test

# البناء
flutter build apk --release                     # ملف APK واحد
flutter build appbundle --release               # حزمة المتجر (مفضَّلة للنشر)
```

**المخرجات المتوقَّعة**

```
build/app/outputs/flutter-apk/app-release.apk
build/app/outputs/bundle/release/app-release.aab
```

**قبل الرفع إلى المتجر**

1. أنشئ مفتاح توقيع خاصًا:
   `keytool -genkey -v -keystore ~/dhikri-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias dhikri`
2. أنشئ `android/key.properties` (ولا ترفعه إلى git) وأشِر إليه من
   `android/app/build.gradle.kts` بدل `signingConfigs.getByName("debug")`.
3. راجع `applicationId` (`com.adam.dhikri`) — **لا يمكن تغييره بعد النشر**.
